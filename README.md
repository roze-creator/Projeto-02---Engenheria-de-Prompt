# Projeto-02---Engenheria-de-Prompt
# Extraindo Insights do Feedback de Clientes Bancários

## Sobre o projeto

Projeto desenvolvido como parte do Desafio Criativo da DIO, utilizando Engenharia de Prompts e Inteligência Artificial para analisar feedbacks de clientes bancários.

O objetivo foi construir um prompt capaz de orientar uma IA na identificação de reclamações recorrentes, classificação de urgência e proposição de possíveis soluções.

---

## Objetivo

Desenvolver um processo de análise de feedbacks que permita:

- identificar problemas recorrentes;
- classificar reclamações por urgência;
- propor possíveis soluções;
- relacionar soluções aos problemas que podem resolver;
- organizar os resultados de forma estruturada.

---

## Dados utilizados

Foi criada uma base fictícia contendo reclamações de clientes bancários.

Os dados utilizados possuem os seguintes campos:

| Campo | Descrição |
|---|---|
| ID | Identificador fictício do registro |
| Data | Data do feedback |
| Canal | Canal utilizado pelo cliente |
| Produto | Produto ou serviço relacionado |
| Nota | Avaliação atribuída pelo cliente |
| Feedback | Texto da reclamação |

> **Importante:** os dados são fictícios e foram criados exclusivamente para fins educacionais. Nenhum dado pessoal ou financeiro real foi utilizado.

---

## Construção do Prompt

O prompt foi desenvolvido considerando:

1. **Papel da IA** — profissional do setor de SAC;
2. **Objetivo** — analisar reclamações bancárias;
3. **Critérios de análise** — frequência e urgência;
4. **Soluções** — identificação de possíveis ações;
5. **Complexidade** — classificação das soluções da mais simples à mais complexa;
6. **Formato de saída** — tabela estruturada;
7. **Restrições** — utilização exclusiva dos dados fornecidos e ausência de informações inventadas.

---

## Estrutura da análise

A IA foi orientada a identificar:

- problemas e temas recorrentes;
- frequência das reclamações;
- nível de urgência;
- possíveis soluções;
- complexidade das soluções;
- reclamações que podem ser resolvidas por cada solução.

---

## Resultado

A análise foi estruturada em uma tabela contendo:

| Problema/Tema | Frequência | Urgência | Solução | Complexidade | Casos relacionados |
|---|---|---|---|---|---|

A estrutura permite transformar comentários individuais em informações mais organizadas para apoiar a identificação de prioridades no atendimento ao cliente.

---

## Aprendizados

O desenvolvimento do projeto demonstrou a importância de fornecer à IA:

- contexto suficiente;
- critérios claros de análise;
- formato de resposta definido;
- restrições explícitas;
- dados estruturados.

Também foi possível observar que a qualidade do resultado depende diretamente da qualidade das instruções fornecidas e dos dados utilizados.
